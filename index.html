SysBeacon

Automated PC Telemetry Agent

SysBeacon is a lightweight background telemetry agent designed to track machine activity, uptime, and daily usage patterns using an embedded SQLite database and a local HTTP Web UI dashboard.

  • Automatic Startup via Windows Task Scheduler
  • User AppData persistence model
  • Built-in visual heatmap and database explorer
