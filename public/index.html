What SysBeacon Does:

It quietly tracks your PC usage in the background, recording uptime statistics every minute into a local database to show you clean visual activity heatmaps.

Setup & Installation (WINDOWS x64)

Download and set up automatic startup via Windows Task Scheduler.

SysBeacon.zip
ZIP Archive • Includes Binary & Setup Guide
Download SysBeacon.zip

👉 Extract SysBeacon.zip. To run automatically on login without commands, press Win + R, type taskschd.msc, and hit Enter. Click Create Basic Task, name it SysBeacon, choose When I log on → Start a program, and select SysBeacon.exe. Click Finish, right-click the task in the library, and click Run to test.

How to Access Dashboard

Open your browser or use the system tray menu:

URL: localhost:321
Tray Option: Right-click the SysBeacon icon in the bottom Windows taskbar right side and click Dashboard.
